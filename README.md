# PulseFi Platform

Welcome to the PulseFi repository. This project is structured using dedicated development branches for better scalability and deployment isolation.

## 🌿 Repository Structure

To explore the source code, please switch to the respective production or development branches:

*   **Frontend Production:** Switch to [`main-fe` branch](https://github.com/mapleury/pulsefi-backend/tree/main-fe) (Vite + Tailwind CSS Layouts)
*   **Backend API Production:** Switch to [`main-be` branch](https://github.com/mapleury/pulsefi-backend/tree/main-be) (Node.js API Services)
*   **Frontend Staging:** Switch to `staging-fe` branch
*   **Backend Staging:** Switch to `staging-be` branch
